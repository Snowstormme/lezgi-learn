# Руководство по контенту (Словарь и Уроки)

Весь контент курса и словаря хранится в папке `content/` в формате JSON. Это позволяет добавлять слова и уроки без изменения React-компонентов и отслеживать каждую правку в Git.

## 1. Правило лезгинской палочки (`Ӏ`)
В лезгинской кириллице используется буква **палочка (`Ӏ`, Unicode U+04C0)** в смычно-гортанных согласных (`кӀ`, `пӀ`, `тӀ`, `цӀ`, `чӀ`).
- Схема валидации (`content/schema.ts`) автоматически нормализует `к1`, `кI`, `кl`, `к|` после согласных в эталонную `кӀ` перед записью в БД.
- При прохождении упражнения `word_input` ученик может вводить с клавиатуры `1`, `I`, `l` или `|` — функция `isLezgiAnswerCorrect()` в `lib/lezgi-utils.ts` засчитает ответ как правильный.

## 2. Как добавить новое слово
Откройте `content/dictionary/core-words.json` и добавьте объект:

```json
{
  "slug": "kval",
  "lemma_lez": "кӀвал",
  "translation_ru": "дом / комната",
  "transcription_ru": "кӀвал",
  "part_of_speech": "noun",
  "grammar_notes_ru": "Во множественном числе: кӀвалер.",
  "status": "draft",
  "examples": [
    {
      "slug": "kval-ex-1",
      "sentence_lez": "Им чи кӀвал я.",
      "translation_ru": "Это наш дом.",
      "status": "draft"
    }
  ]
}
```
> Пока носитель не проверил запись, ставьте `"status": "draft"` или `"pending_review"`. После проверки носителем переведите в `"published"`.

## 3. Как добавить новый урок
Создайте JSON-файл в `content/courses/ru-lez/<unit-folder>/lessons/<number>-<slug>.json`:
- Поддерживаемые типы упражнений (`type`):
  1. `multiple_choice` — выбор правильного перевода из 2–6 вариантов (`question`, `options`, `correct_index`).
  2. `matching` — сопоставление пар (`pairs: [{ left, right }]`).
  3. `word_input` — письменный ввод слова на лезгинском (`accepted_answers: ["..."]`).

## 4. Проверка и загрузка в Supabase
1. Проверить все JSON-файлы без обращения к БД:
   ```bash
   npm run content:validate
   ```
2. Загрузить (идемпотентный `UPSERT` по `slug`) в облачный проект Supabase:
   ```bash
   npm run db:seed
   ```
