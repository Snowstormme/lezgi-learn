# Feature Module: `community` (Stage 4 — Planned)

> **Статус в v0 (Этап 1):** Папка-резерв без бизнес-логики. В схеме БД v0 уже заложена базовая таблица `content_reports` с RLS-политиками, но пользовательский и модераторский интерфейс сообщества вынесен на Этап 4.

## Назначение модуля
1. **Сообщения об ошибках (`content_reports`):**
   - Любой авторизованный ученик может отправить репорт на слово (`word`), пример (`word_example`), упражнение (`exercise`) или урок (`lesson`), если заметил опечатку или неточность.
2. **Предложения новых слов и фраз (`content_suggestions` — Этап 4):**
   - Предложение новых примеров, диалектных вариантов и исправлений со статусом `pending_review`.
3. **Панель ревьюера (носителя языка):**
   - Очередь проверки записей в статусе `pending_review` с переводом в `published` или `rejected`.
